Python 試行錯誤場

Python 3 を読み込み中（初回は数十秒）
辞書から読み込む選ぶとコードと入力欄が入れ替わります
コードTab でインデント / Ctrl+Enter で実行
入力データinput() が上から1行ずつ読みます
結果
まだ実行していません

これは本物の CPython です。Pyodide（WebAssembly 版 Python 3）をブラウザ内で動かしているので、文法エラーも例外も手元の python3 と同じ結果が出ます。

無限ループに注意。while True を break なしで書くとタブが固まります。復帰はタブを閉じるしかありません。

初回だけ通信します。Python 本体を CDN から取ってくるため、最初の起動にはネット接続が必要です（約 10MB）。2回目以降はブラウザのキャッシュから起動します。
